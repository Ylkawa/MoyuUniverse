## 提示词与输入

四个环节分别补强：

- **知识提取**：分别遮住另一字段检查，问题和结论各自必须能定位同一主体及必要范围。只补定位必需的归属；允许同字段内有唯一先行对象的代词和无歧义简称，避免机械扩写。
- **研究入库编排**：每个来源的每个事实段都保留主体及范围。研究任务、完整报告用于判断相关性和是否采纳，不能代替该 URL 的证据；旧摘要和后续官方核查不能互相借用证据。
- **事实匹配**：缺失限定不是通配符，名称近似不证明同一型号。除完整结论互相蕴含外，双方结论还应各自能完整回答另一方问题，防止旧摘要问句配上另一来源的官方答案。
- **冲突判断**：先定位同一对象和适用范围，再判断断言是否相容。不能把正待比较的阈值预先要求相同；不同版本、事件或样本可并存，未确认冲突也不意味着可以合并。

补足了比较双方、匿名样本的可定位范围、机构属地、作品归属、型号后缀，以及事件时间、报道时间和核查时间的区别。匿名样本并非一律无价值，但不能据一个样本推成整个类别的规律，也不能虚构品牌或型号。

提取调用现在分别传入：

1. 系统中的业务规则及结构化输出契约；
2. JSON 序列化的来源标题和 URL，作为用户消息中的定位数据；
3. 当前正文块，作为另一条用户消息。

标题只可辅助消歧作品或产品归属，不能补正文没有的数值、能力等事实；URL 不用于猜型号、日期或内容。标题与正文归属冲突时省略受影响条目。原来只传正文块、未提供来源定位的接口已替换，没有保留旧签名或增加输出字段。原有入库资格、置信度、复查期限和证据限制规则继续有效。
