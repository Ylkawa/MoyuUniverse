# Circle line background

circle-lines-alpha.png is a clean geometric RGBA asset, 1200 × 1200.
Drawn with antialiased circular outlines; RGB 109/151/146, alpha up to 58/255.
No noise, grain, shadows or filled shapes. Rendering preserves aspect ratio with centered cover cropping.
The cached display copy smoothly fades from transparent on the left toward the original alpha on the right; the source PNG is unchanged. Page opacity is 24%, card opacity 30%. Text and borders are painted above the texture.

The image-generation drafts were rejected because they contained irregular artifacts. The final asset uses deterministic geometric drawing.
