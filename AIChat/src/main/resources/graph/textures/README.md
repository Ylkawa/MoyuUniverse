# Circle line background

circle-lines-alpha.png is a clean geometric RGBA asset, 1200 × 1200.
Drawn with antialiased circular outlines; RGB 109/151/146, alpha up to 58/255.
No noise, grain, shadows or filled shapes. Rendering preserves aspect ratio with centered cover cropping. Composited beneath text and borders at restrained opacity.

The image-generation drafts were rejected because they contained irregular artifacts. The final asset uses deterministic geometric drawing.
